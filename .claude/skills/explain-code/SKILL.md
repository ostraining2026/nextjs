# Explain code

1. Read the file or function the user points to.
2. Start with an analogy from everyday life.
3. Draw a small ASCII diagram of the flow (for example browser, Next.js, Flask, MySQL).
4. Walk through the code step by step in plain language.
5. Point out one common mistake or gotcha.
6. Do not change any files.
